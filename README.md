# 하원콜 · 서울 통학과 등하원

순정 내비의 기존 경로를 유지하며 기관 접근, 정차, 보호자 탑승·인계 확인을 연결하는 차량 앱입니다. 서울의 학교·유치원·어린이집·학원을 대상으로 합니다.

## 브라우저 시연

**[차량 화면 열기](https://lkjh098-cell.github.io/hawoncall-demo/)** · **[보호자 화면 열기](https://lkjh098-cell.github.io/hawoncall-demo/?view=guardian)**

현대자동차그룹이 2026년 4월 공개한 Pleos Connect 화면 배치를 참조해 상단 상태바·좌측 주행 뷰·우측 입체 지도·하단 공조 및 앱 바를 재구성했습니다. [공식 참조 자료](DESIGN_REFERENCE.md)를 확인하세요. 지도는 OpenFreeMap의 실제 OpenStreetMap 기반 벡터 자료와 저장된 서울 도로 경로를 사용합니다. 차량 위치·기어·문·좌석·학생·완료 기록은 가상 데이터입니다. 시연 화면은 실제 현대차·Pleos OS의 공식 화면이 아니며, 실행 중인 차량을 제어하지 않습니다. 인터넷 지도 연결과 WebGL을 지원하는 브라우저가 필요합니다.

화면 아래 **주행 시작**을 누르면 실제 도로 경로를 따라 가상 차량과 지도가 움직입니다. **1× 실제 시간 / 3× 빠르게 / 6× 발표용** 중 선택하고 **반복**을 켜면 D 근접 지점에서 5초 뒤 다시 출발합니다. **전체 화면** 버튼으로 발표할 수 있습니다. 기관 유형과 등교·하교/등원·하원 방향은 **시연 조작**에서 선택합니다. 하단 h 아이콘으로 하원콜을 펼치면 내비 옆의 분할 앱 창이 됩니다. 접근한 뒤 발표자가 P 정차를 선택하고, 차량 화면에서 보호자가 실제 탑승 또는 인계를 확인하는 과정을 체험합니다. 브라우저의 보호자 화면은 같은 출처·브라우저에서 열린 시연 상태를 공유하며 실제 휴대폰 서버 연동이 아닙니다. 실시간 교통·도로 통제·정차 허용 여부를 반영한 운전 안내로 사용하지 않습니다.

## 0.14 · 직원용 경험 시연과 회전 도로

**[직원용 시연 열기](https://lkjh098-cell.github.io/hawoncall-demo/?present=1)**

‘아이 위치와 도착 시간을 한 화면에서 본다’는 첫 장면으로 시작해 보호자 일정, 아이 위치 공유, P에서 목적지 검토, D 접근·주정차 구역 가정, 직접 탑승 확인, 다음 일정 음성, 기관 준비·문제 요청, 차량 앱 체험을 9개 장면으로 엮었습니다. 차량 UI 바깥의 **직원용 시연** 패널에서 장면을 고르면 실제 해당 기능 화면이 열립니다. 주요 기능 17개의 열람 목록과 구현 범위가 함께 있습니다. ‘둘러본 기능’은 해당 화면을 열었다는 뜻이며 동의·저장·요청·확인 성공을 뜻하지 않습니다.

첫 장면은 가상 아이 위치와 3× 가상 주행을 함께 시작합니다. 아이 GPS 권한은 요청하지 않습니다. 다른 장면을 열 때 재생을 멈추고 반복 재생을 끄므로 설명할 수 있습니다. 아이 위치 미리보기 이후에는 기관 경로의 도착 절차를 별도 시연합니다. GPS 목적지의 후속 탑승 절차가 완성된 것으로 보여주지 않습니다.

보호자 화면의 **가상 예시 일정 불러오기**는 편집칸만 채웁니다. 사용자가 **오늘 일정 저장**을 눌러야 차량 안내에 반영됩니다. 위치 권한·목적지 변경 동의·보호자 확인·음성 사용도 직접 선택하며 장면 전환으로 자동 확정하지 않습니다. 가상 차량의 P·문·좌석은 발표 장면을 위한 모형 상태입니다.

왼쪽 도로를 오른쪽 내비와 **같은 경로 좌표와 방향**으로 그립니다. 전방 경로에 맞춰 도로·경계·차선·가상 주변 차량이 휘며, 회전 후에는 차량의 새 방향을 기준으로 다시 정렬됩니다. 실제 감지한 차선이나 주변 차량을 나타내는 ADAS 구현은 아닙니다. 웹 시연의 시스템 UI 모형이며 실차 적용 구상은 순정 시스템 주행 뷰를 유지하는 하원콜 앱 창 연동입니다.

검사 **112/112 통과**. 브라우저에서 실제 우회전 경로에 맞춘 도로 곡선, 9개 장면·17개 기능 열람, 일정 저장→탑승 후 안내문, 가상 아이 위치의 공개 OSRM 도로 조회, 직접 확인 전후 구분을 검수했습니다. 0.11 네이티브 소스·빌드 자료가 준비되어 있으며 이번 0.14는 웹 시연 개선입니다.

### 현대차 직원에게 제시할 가치와 검증

- 첫 30초: 차가 기존 경로를 따라 움직이고, 아이의 가상 위치가 같은 지도에 갱신되는 경험을 보여줍니다.
- 핵심 흐름: 아이 위치 검토 → P에서 목적지 동의 → 기관 경로의 접근·정차 예시 → 보호자 확인 → 다음 일정 안내.
- 자유 체험: 보호자 일정, 기관 준비·예상 대기, 지연·장소 변경 요청, 네 종류 기관, 앱 라이브러리·공조·미디어·전화·라디오.
- 파일럿 검증 제안: 픽업 대기시간, 휴대폰 조작 횟수, 만남 지점 재조정 횟수, 위치 오차·만료 상황의 처리율. 개선 효과는 아직 측정하지 않았습니다.

[공식 내비 개발 가이드](https://document.pleos.ai/en/docs/pleos-only/vehicle-app-developer-guide/navigation-app-development-guide)의 단일 경로·명시적 변경 동의·주행 중 조작 최소화를 설계 참고로 삼았습니다. 공식 제휴·플랫폼 심사 통과·실차 검증을 의미하지 않습니다.

## 0.13 · 주행 움직임·지도 추적 수정과 도착지 안내

왼쪽 주행 뷰의 차선과 주변 차량이 도로 진행 거리·재생 배속에 맞춰 움직입니다. 자차는 운전 화면의 기준 위치에 있고, 도로와 주변 차량의 상대 이동 및 회전 표현으로 전진을 보여줍니다. 일시 정지·P·D 접근 정지에서는 화면 움직임도 멈춥니다.

오른쪽 지도는 차량과 카메라를 매 프레임 같은 지리 좌표로 갱신합니다. 차량 기준점은 지도 너비 50%, 높이 72%입니다. 지도 전체 경로 보기·손으로 이동 후 **차량 따라가기**를 한 번 누르면 최신 차량 위치로 복귀하며, 주행 시작 때도 추적을 다시 켭니다. 앱에서 지도로 돌아오거나 창 크기를 바꿔도 현재 위치로 복구됩니다.

도착지 150m 이내 D 접근과 P 정차에서 **주정차 금지구역이에요 / 주정차 가능구역이에요 / 주정차 가능 여부를 확인해 주세요** 안내를 표시합니다. **시연 조작 → 도착지 주정차 안내**에서 가상 시나리오를 선택합니다. 기본값은 금지구역을 가정한 안내입니다. **이는 실제 지도 좌표의 규제를 판정한 결과가 아닙니다.** 모든 안내에 ‘시연 시나리오 · 실제 도로 규제 미확인’을 표시하며, 확인된 아이 GPS 목적지의 도로 미리보기에는 기관 시나리오 안내를 띄우지 않습니다. P 기어·도착·학습 기록으로 주정차 허용을 만들어내지 않습니다.

웹 검사 **102/102 통과**. 실제 브라우저에서 차선·주변 차량 변화, 주행 중 차량 마커 위치 유지, 수동 지도 이동 후 한 번에 복귀, D 접근과 P 정차의 안내를 확인했습니다. Android·실차 규제 데이터 연동은 이번 웹 수정에 포함되지 않습니다.

## 0.12 · 주행 재생과 터치 앱 전환

하단의 **차량 정보·공조·미디어·전화·내비게이션·앱 라이브러리·지도·라디오·하원콜** 아이콘을 클릭하거나 터치하면 해당 화면이 열립니다. 온도·바람·성에 제거 아이콘도 공조의 관련 조작으로 연결됩니다. 앱 라이브러리에서 앱을 고르고 뒤로·닫기·내비게이션으로 돌아갈 수 있습니다. 앱을 오가도 지도 위치와 시연 주행 상태는 유지됩니다.

현대 Pleos 공식 디자인 문서의 좌측 주행 뷰, 우측 앱 창, 하단 GNB와 앱 라이브러리 구조를 반영한 **동작 가능한 화면 모형**입니다. 전화·미디어·라디오·공조·차량 설정은 로컬 화면 시연이며 통화·음악 재생·실차 제어를 실행하지 않습니다. 미디어의 **오늘 일정 음성**은 기존 일정 안내 화면으로 연결됩니다.

1×는 저장된 도로 경로의 주행 소요시간을 기준으로 재생합니다. 3×·6×는 재생 시간을 압축하며 실차 속도 신호가 아닙니다. 반복 재생은 접근 구간만 되풀이하며 P 정차·탑승 신호·보호자 확인을 자동으로 만들지 않습니다. 다른 브라우저 탭으로 이동하면 주행을 일시 정지합니다. 다시 돌아와 **주행 시작**을 누르세요.

웹 검사 **89/89 통과**. 브라우저에서 주행·앱 전환·공조 조작·지도 복귀를 확인했습니다. 네이티브 Android·서버 기능은 v0.11과 같습니다.

## 0.11 · 아이 휴대전화 GPS와 실시간 만남 위치

**[아이 위치 공유 화면](https://lkjh098-cell.github.io/hawoncall-demo/?view=child)**

차량 화면 아래 시연 조작 → **가상 아이 위치 시연**을 누르면 실제 서울 지도에 이동하는 가상 아이 위치·정확도 원·수신 경과시간이 표시됩니다. 정차 중 **이 위치를 목적지로 확인**하면 해당 좌표까지 실제 도로 경로를 조회합니다. 브라우저 도로 미리보기는 OSRM을 사용하며 실차 순정 내비 안내가 아닙니다. 현재 위치 마커는 갱신되고, 확인한 목적지는 고정됩니다. 자동 재탐색하지 않습니다.

아이 화면은 명시적으로 동의·시작한 경우에만 휴대전화 GPS를 요청합니다. 서버를 연결하지 않은 브라우저 공유는 같은 브라우저 탭 사이에서만 동작합니다. 실제 기기 간 공유에는 같은 HTTPS 서버와 역할별 인증, 보호자가 발급한 일회용 코드가 필요합니다. 서버의 HTTPS `/child` 주소에서는 같은 출처의 실제 아이 연결을 사용할 수 있습니다. 실제 아동 정보를 공개 가상 시연에 입력하지 마세요.

네이티브에는 별도의 아이 위치 공유 앱이 추가되었습니다. 실제 기기 GPS를 명시적 시작·지속 알림·중지 버튼으로 공유하며, 보호자와 연결 차량만 최신 위치를 조회합니다. 정확도50m 이내·관측30초 이내·서울 범위만 받고 최신 점도 만료·중지 후 폐기합니다. 공유 세션은30분 이내, 좌표 이력은 저장하지 않습니다. 서버 재시작 시 다시 연결해야 합니다.

Pleos 앱은 정차 중 확인한 아이 위치를 실제 NaviHelper3.0.5 `requestRoute`로 전달하고 실제 콜백으로 결과를 구분합니다. 이때 기존 기관 기준 도착·탑승 자동 처리를 일시 중지합니다. 다른 지점에서의 별도 탑승 완료 절차는 아직 보완이 필요합니다. GPS로 주정차 허가나 차량의 도착·아이 탑승을 확정하지 않습니다.

실제 HTTPS 서버는 배포하지 않았으며, 실물 휴대전화 GPS와 실차 내비·알림 동작은 검증 전입니다. 연결·서버 실행 문서는 네이티브 소스의 `docs/GPS_SETUP_V11.md`에 있습니다. Docker 실행 파일도 포함했으나 Docker 자체는 이번 환경에서 검증하지 않았습니다.

## 0.10 · 기관 운영과 오늘 일정

하원콜을 펼치면 **만날 장소 / 준비 상태 / 문제 알림 / 오늘 일정**을 선택합니다. 기관의 가상 준비 선언은 아래 시연 조작에서 바꿉니다. ETA와 준비까지 시간을 비교해 예상 대기를 표시하며, 선언이 오래되면 미확인으로 표시합니다. 출입구 안내는 정차 허가가 아닙니다.

보호자 화면에서 가상 일정 최대 8개와 준비물·당부를 저장하면 차량 카드에 반영됩니다. 미디어 앱의 오늘 일정 음성 또는 오늘 일정의 음성 버튼을 열어 P에서 동의한 뒤 짧게 들을 수 있습니다. 출발·직접 탑승 확인 후 각 한 번, 최대 3개 남은 일정과 알림을 안내합니다. 음성 엔진의 시작 응답이 없으면 화면 안내문과 실패 상태를 표시합니다. 브라우저 음성은 실제 차량의 음악·오디오 포커스와 연결되지 않습니다.

문제 알림의 정차 공간 없음·아이 준비 지연·다른 장소·취소는 기관에 보내는 가상 요청입니다. 기관 응답은 시연 조작에서 작성합니다. 요청과 회신은 경로 변경·자동 취소·탑승 확인을 실행하지 않습니다. 모바일은 운행 완료를 확정할 수 없습니다. 공개 화면에는 가상 일정만 입력하세요.

네이티브 소스에는 인증된 보호자 일정 저장·차량 조회·기관 운영 API, 날짜·최신성 검사, Pleos TextToSpeech 3.3.1 ON_DEVICE 어댑터와 Android 오디오 포커스 연결이 포함됩니다. 실제 차량의 음성·미디어 공존 및 설치는 실기 검증 전입니다. 외부 캘린더·마이현대·음악 서비스 계정에 연결된 결과는 아닙니다.

## 소스 구성

- `index.html`: GitHub Pages에서 바로 실행하는 통합 시연 화면.
- [web-source-v0.14.zip](web-source-v0.14.zip): 브라우저 시연 소스, 실제 경로 자료, 테스트와 빌드 도구.
- [native-source-v0.11.zip](native-source-v0.11.zip): Android 차량 앱·보호자 라이브러리·서버 소스. 실제 차량 신호는 이 압축 파일의 Pleos 어댑터에서 담당합니다.

GitHub Pages는 HTML/JS 화면을 제공하며 Node/SQLite 서버나 Android APK를 실행하지 않습니다. 실제 차량·모바일 운영은 별도 HTTPS 서버와 차량 권한·설치·실기 검증이 필요합니다. 마이현대 공식 앱에 통합된 결과는 아닙니다. 개발용 APK·AAR와 기기 연결 DB·토큰·비밀번호는 저장소에 포함하지 않습니다.

## 서울 자료와 지점 학습

네이티브 서버에는 서울 교통소통 도로 5,080개 구간, 주차장 참고 위치 117곳, 어린이보호구역 지정 시설 주소 1,630건이 있습니다. 자료 출처·기준일·가공 범위는 `native/docs/SEOUL_V07.md`, 원본 해시는 `native/server/data/sources.json`을 확인하세요.

**참고 위치 117곳은 승하차 허용 지점이 아닙니다. 현재 현장·허가가 검증된 지점은 0곳입니다.** 운영자가 허용 근거를 검증한 뒤에만 선택과 대기시간 학습이 열립니다. 반복 정차나 학습으로 허가를 만들어내지 않습니다. 브라우저 시연에서 실제 허용 지점을 가장하지 않습니다.

v0.11 서버 API 검사 95건과 웹 모델·지도·동기화·음성·GPS 정책 검사 81건이 통과했습니다. Android 빌드·검사 결과는 네이티브 소스의 docs/VERIFICATION_V11.md를 확인하세요. 실제 Pleos 차량에서의 설치·주행 검증은 아직 하지 않았습니다. 웹 모델과 Kotlin 차량 엔진은 서로 다른 코드이며 브라우저 결과를 차량의 안전 판정에 사용하지 않습니다.

## GitHub Pages 설정

저장소 Settings → Pages → Deploy from a branch → `main`, `/(root)`를 선택합니다. `.nojekyll`로 정적 파일을 그대로 제공합니다. 시연에는 비밀 API 키와 운영 계정이 필요하지 않습니다. 웹 소스 압축을 푼 뒤 `cd web && node build-standalone.mjs`로 재생성하고, `python3 -m http.server 4175 --directory dist`로 로컬에서 열 수 있습니다. `node --test screen/*.test.mjs`로 검사합니다.
