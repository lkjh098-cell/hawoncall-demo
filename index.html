실제인 것과 가상인 것

OpenStreetMap 지도와 미리 저장한 OSRM 도로 경로는 실제 지리 자료예요. 차량 이동, ETA, 기어, 문·착석, 기관 알림, 보호자 기록은 모두 시연 데이터예요. 실제 기관명·아동 정보·사용자 GPS를 사용하지 않아요.

저장과 통신

같은 출처의 탭을 연결하기 위해 로컬 저장소에 시연 단계와 선택값만 저장해요. 지도가 보이는 범위의 OpenStreetMap 타일 외에 서버·인증·실차 API에 연결하지 않아요. 하원콜 알림을 외부로 발송하지 않아요.

보호자의 마지막 확인

PICKUP은 보호자의 실제 탑승 확인, DROPOFF는 보호자의 직접 인계 확인으로만 마무리해요. 문·좌석 센서는 기관 입실을 증명하지 않아요. D 근접과 P 주차는 서로 다른 단계예요. DROPOFF는 P 주차 후 직접 인계를 확인하며 하차 신호는 필수 조건이 아니에요.

Pleos Connect의 화면 구성에서 영감을 받은 제안 시연이에요. 현대자동차·Pleos의 공식 제품이나 승인된 차량 연동을 의미하지 않아요. 실제 운전용 내비게이션으로 사용할 수 없어요.
